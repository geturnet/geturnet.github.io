## 📖 Tentang Proyek

**Geturnet Ltd** (`https://geturnet.github.io/`) adalah platform blog modern berstandar SEO tinggi yang dirancang khusus untuk menyajikan artikel berkualitas tinggi di berbagai bidang strategis, mulai dari strategi finansial/investasi, tutorial pemrograman tingkat lanjut (PHP, WebDev, Cloud), hingga layanan konsultasi dan audit SEO gratis.

Repository ini dilengkapi dengan skrip otomatisasi berbasis Python untuk men-generate ratusan halaman artikel terstruktur secara cepat, lengkap dengan optimasi Schema Markup (JSON-LD), integrasi Google AdSense, serta tata letak responsif.

---

## ✨ Fitur Utama Platform

1. **Struktur SEO Komprehensif:**
   * Meta Title, Description, Keywords, dan Canonical Tag dinamis.
   * Open Graph & Twitter Cards untuk optimasi sosial media (Facebook, Twitter, LinkedIn).
   * **Structured Data (JSON-LD Schema):** Mendukung format *Organization*, *WebSite*, *Article*, dan *FAQPage* untuk mempercepat indeksasi mesin pencari Google.
2. **Monetisasi Google AdSense:**
   * Terintegrasi langsung dengan publisher ID: `ca-pub-4549220738609468`.
   * Penempatan slot iklan responsif di bagian atas, tengah, dan sidebar artikel.
3. **Arsitektur Konten Masif (300+ Artikel):**
   * Dibagi menjadi **10 Label/Kategori Utama**, di mana masing-masing kategori memuat 30 artikel unik berformat hierarki heading lengkap (`H1` hingga `H6`).
4. **Komponen Interaktif & Sidebar Modern:**
   * Slider Gambar Unggulan (Featured Slider).
   * Widget Tren Terkini (*Trending Topics*).
   * Widget Postingan Populer (*Popular Posts*).
   * Cloud Label / Kategori Interaktif.
   * Arsip Bulanan Artikel.
   * Formulir Kontak & Permintaan Audit SEO.
   * Navigasi Halaman Legal (Privacy Policy, License, Disclaimer, Sitemap).
